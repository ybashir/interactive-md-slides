# Community conduct

Be respectful, constructive, and considerate of people with different backgrounds and experience. Discuss the code and evidence, give useful feedback, and respect personal and confidential information.

Harassment, discrimination, threats, personal attacks, and publishing someone else's private information are unacceptable in project issues, pull requests, discussions, and other project spaces.

Yasser Bashir (@ybashir) maintains this project and may edit or remove inappropriate content, close disruptive threads, or restrict participation. For a sensitive conduct concern, ask the maintainer for a private contact method without posting personal details publicly. Maintainers will consider reports fairly and protect confidential details where practical.
