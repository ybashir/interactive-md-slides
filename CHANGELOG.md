# Changelog

## 0.1.0 — initial open-source release candidate

- MIT licensing for original code and sample artwork, with upstream Slidev notices.
- Generic Google creator access through a Workspace domain or verified-email allowlist.
- Browser-bound OAuth, server-side audience result privacy, restricted export workspaces, and stronger production configuration.
- Durable asset deletion/retry, audience session expiry, configurable record retention, and AI/privacy disclosures.
- Updated dependencies with verified temporary upstream security patches and scheduled audits.
- Self-hosting Compose, setup tooling, contributor/security documentation, secret scanning, CodeQL, and database/browser regressions.

The release remains a candidate until its fresh public repository passes the public-only checks described in [releasing](docs/releasing.md).
